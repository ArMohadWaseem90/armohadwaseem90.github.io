🎬 Multiviewer - See All Your Video Sources at Once

Multiviewer is a multi-protocol video multiviewer for Windows. It takes every video feed you have — cameras, capture cards, screen shares, and network streams — and places them side by side in a single window, so you can watch everything at the same time instead of switching between apps.

🔍 What Is a Multiviewer?

A multiviewer is a screen that shows several video feeds at once, arranged in a grid. You have almost certainly seen one: the wall of monitors in a security office, or the bank of screens in a sports broadcast control room where the director can see every camera angle together.

Multiviewer gives you that same idea on a normal Windows computer. Instead of opening one program for your webcam, another for your capture card, and a third for a network video feed, you open Multiviewer once. Each source gets its own tile, and you decide how big each tile is and where it sits.

The application is built around the idea that video does not have to come from one place. Different devices speak different "languages" — some use DirectShow, some use Media Foundation, some send video over the network with NDI, and some use DeckLink hardware. Multiviewer understands all of these and treats them equally, which means you are not locked into one brand of hardware.

✨ What You Can Do With Multiviewer

Watch everything in one window

Add as many sources as your computer can comfortably handle and see them all together. No more minimizing and maximizing windows to check whether a camera is still live.

Mix hardware from different makers

A USB webcam, a professional capture card, a network stream, and a screen share can all live in the same grid. You do not need matching equipment.

Arrange the layout your way

Give the most important feed the largest tile and keep the rest as smaller previews. Rearrange tiles whenever your setup changes.

Keep an eye on several things at once

Useful for monitoring a live stream while also watching your own screen, checking multiple cameras during a recording, or keeping a remote feed visible while you work.

🎥 Video Sources You Can Add

Multiviewer is described as multi-protocol for a reason. It is built to speak to many kinds of video sources through one interface:

  • NDI — network video streams sent from other computers or devices on the same network.
  • DeckLink — professional capture and playback hardware.
  • DirectShow — the classic Windows way of talking to webcams, capture cards, and virtual cameras.
  • Media Foundation — the newer Windows video framework, used by many modern cameras and devices.
  • Screen Capture — grab a window or a whole desktop display and show it as a tile.
  • Spout2 — receive video that other applications on the same PC are sharing.
  • AVFoundation and Syphon — source types from the wider Multiviewer project, intended for Apple hardware.

You do not need to install anything extra to use the Windows source types. If a device already appears in other video software on your machine, there is a good chance Multiviewer can see it too.

🖥️ Getting Started for the First Time

  1. Open the releases page. Use the download button above or the link in the previous section. The newest release is at the top of the list.
  2. Download the application from that page. The download begins once you choose the file offered on the page, and it is saved to your Downloads folder.
  3. Open the file you downloaded. If Windows asks whether you want to allow the application to run, confirm so that it can start.
  4. Connect your video sources before you look for them. Plug in your cameras and capture cards, and make sure any screen share or network stream you plan to use is already running. Multiviewer can only see a source once the source is actually available.
  5. Add your first tile. In Multiviewer, open the list of available sources and pick one. It appears as a tile in the main window.
  6. Repeat for each additional feed. Add the rest of your sources one at a time. Start with two or three, confirm that each one shows a picture, and then add more.
  7. Adjust the layout. Drag the tiles until the arrangement suits the way you work, and resize the important ones so they are easy to see at a glance.

That is the whole process. There is no account to create, no subscription to manage, and no cloud service to sign into. Everything runs locally on your own computer.

💡 Tips for a Smooth Experience

  • Start small. Add one source, confirm it works, then add the next. If something does not appear, you immediately know which feed caused it.
  • Give your computer some breathing room. Every tile is a live video stream, and live video uses processing power. If the picture becomes choppy, remove a tile or two and check whether things recover.
  • Keep source windows visible where needed. Some sharing methods only send video while the original application is open and running.
  • Use wired connections for network video. A network camera or stream is far more stable over a cable than over a weak wireless signal.
  • Update when you notice a new release. The releases page shows the newest version first, so a quick visit tells you whether anything has changed.

🧩 What You Need

Multiviewer is designed for Windows. A reasonably modern computer with a current version of Windows and a working graphics driver is the right starting point. Because video work is demanding, a machine that handles other video software comfortably will handle Multiviewer comfortably too.

Beyond the computer itself, you need whatever sources you plan to watch: a webcam, a capture card, a phone or computer sending an NDI stream, or a display you want to mirror. The more sources you add at once, the more capable your computer should be. If you are unsure, begin with a single source and add more gradually — that is the most reliable way to find the limit of your particular machine.

In short

  • A Windows computer with a current graphics driver.
  • At least one video source connected or running.
  • Enough spare processing power for the number of tiles you want.

🛠️ Troubleshooting

My camera does not appear in the source list.

Close Multiviewer, plug the camera in, wait a moment, then reopen the application. Also check that no other program is currently using the camera — many cameras can only be opened by one application at a time.

The download page shows a list of versions.

That is expected. The releases page groups files by version, with the newest at the top. Choose the newest version and use the download offered there.

The picture is not smooth.

Reduce the number of tiles on screen, or lower the size of the largest tiles. Live video is heavy work, and fewer or smaller streams leave more room for the ones you are actually watching.

A network source stays black.

Confirm the sending device is still running and that both computers are on the same network. Network video needs an active sender at all times.

❓ Frequently Asked Questions

Is Multiviewer free to download?

The application is distributed through its public releases page on GitHub. Visit the download link above to see the available versions and what each one contains.

Do I need to install anything else first?

No extra steps are needed beyond downloading from the releases page and opening the file. If your devices already work in other video software on the same computer, they are ready to use.

Can I use more than one type of source at the same time?

Yes. That is the point of the application. A webcam, a capture card, a screen share, and a network stream can all be shown together in the same grid.

Does Multiviewer change or record my video?

Multiviewer is a viewer. It displays your sources together so you can watch them; it does not alter the original feeds.

📦 About the Project

Multiviewer is built in Rust with a wgpu rendering backend, which is how it can handle many video protocols efficiently while keeping the interface responsive. Its source support spans AVFoundation, DeckLink, DirectShow, Media Foundation, NDI, screen capture, Spout2, and Syphon — a deliberately broad set, so that users are not forced to standardise on a single vendor or a single connector type.

The practical benefit for you, as someone using the application rather than building it, is straightforward: whatever equipment you already own is likely to work. You are not buying new hardware to fit the software.
